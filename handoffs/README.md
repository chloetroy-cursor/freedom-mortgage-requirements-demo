# Delivery Handoffs

After functional review, the live workflow creates:

- `jira-ready.md`: reviewable epics and stories for the current manual Jira
  handoff described in Freedom Mortgage's process.
- `snowflake-loe-input.csv`: scope, dependency, and uncertainty inputs for the
  separate refined-LOE process.

Cursor must not invent delivery estimates or represent a handoff as approval.
